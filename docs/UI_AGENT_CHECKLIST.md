# UI Agent Checklist

## Before

- [ ] Read route and imported components
- [ ] Read shared workspace primitives
- [ ] Run shadcn project info
- [ ] Confirm required components already installed
- [ ] Run git status
- [ ] Start app
- [ ] Capture before screenshot

## During

- [ ] Preserve business logic and actions
- [ ] Use existing UI components
- [ ] Use semantic tokens
- [ ] Avoid page-level horizontal overflow
- [ ] Verify desktop grid contracts
- [ ] Verify right inspector placement
- [ ] Preserve mobile sheets and navigation
- [ ] Avoid unnecessary dependencies

## After

- [ ] Capture after screenshot
- [ ] Verify at 1440, 1366, 1024, 768, and 390px
- [ ] Test keyboard interaction
- [ ] Test empty and missing-data states
- [ ] Run lint
- [ ] Run build
- [ ] List exact files changed
- [ ] Confirm no DB, RLS, auth, query, or server-action changes
